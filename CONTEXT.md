# Adaptive Planning

Adaptive Planner turns work intentions into revisable weekly and daily plans while keeping the planning layers distinct.

## Language

**Weekly Plan**:
A plan that assigns work across the days of one week, specifying which work belongs to each day and how much of it that day should receive.
_Avoid_: Week Schedule, Weekly Calendar

**Day Plan**:
A plan that places one day's assigned work into concrete time intervals around that day's availability and protected commitments.
_Avoid_: Daily Allocation, Day Schedule
